Help

  
Keyboard

  
    
    
  • All keys are sent to the server: F1-F12 (also with Shift/Ctrl/Alt), arrows, Home/End, PgUp/PgDn, Ins/Del, Ctrl and Alt combinations, Esc, Tab.
    • 
    
  • Only these shortcuts belong to the web console: Ctrl+Shift+C / V copy / paste, Ctrl+Shift+F find, Ctrl+Shift+N new connection, Ctrl+Shift+Left/Right switch tab, Ctrl+Shift++/-/0 font size.
    • 
    
  • Fullscreen (Chrome/Edge) enables keyboard lock: then Ctrl+W, Ctrl+T, Ctrl+N, Ctrl+Tab and F11 are also sent to the server. Hold Esc for 2 seconds to leave fullscreen. Outside fullscreen a web page cannot capture these few browser keys.
    • 
    
  • On phones: the Keys button shows a bar with Esc, Tab, Ctrl, Alt, arrows, F1-F12 and more.
    • 
    
  • Selecting text copies it automatically, right click pastes (can be disabled in Settings).
    • 
  

  
Features

  
    
    
  • Quick connect in the header: type user@host:port and press Enter, then enter the password.
    • 
    
  • Tabs: double-click to rename, drag to reorder, middle-click to close. A bold tab name means new output arrived while the tab was in the background.
    • 
    
  • Snippets: saved commands you can send to the active terminal (stored on the server).
    • 
    
  • Profiles can run a startup command after connecting, for example tmux attach || tmux.
    • 
    
  • Files panel: filter, hidden files toggle, drag and drop upload, download (folders as tar.gz), rename, permissions, and an editor for text files up to 1 MB.
    • 
    
  • Settings: light/dark interface, terminal color schemes, line height, and a warning before pasting multiple lines.
    • 
  

  
Notes

  
    
    
  • Sessions keep running on the server for 30 minutes if the page is closed or the network drops. They reconnect when you open the page again.
    • 
    
  • Passwords and keys are never stored - only host, port and user if you save a profile.
    • 
    
  • Host keys are confirmed on first connect and remembered. A changed key triggers a warning.
    •
